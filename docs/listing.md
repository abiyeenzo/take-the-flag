# Roblox experience listing

Text to paste in the Creator Hub (Configure Experience > Basic Settings).

## Title

Capture The Flag: Neon Arena

## Description

Grab the enemy flag and run it home before time runs out!

Fast 5 minute matches, two teams, one glowing arena.

- Pick a class: Striker, Scout or Guardian, each with its own ability
- Level up to unlock new classes
- Earn coins and spend them on trails
- Chain kills for streak bonuses and win the MVP spot
- Overtime sudden death when the score is tied

Controls: click to shoot, Q for your ability, C for classes, B for the shop.

Follow the creator on YouTube: Black-N-Zo

## Settings to check

- Max players: 12 to 16 (the arena is sized for 6v6 to 8v8)
- Enable "Studio Access to API Services" so progress is saved
- Add thumbnails showing a flag run, a gunfight and the class menu
